# 產險教育｜隨機抽車挑戰

## 啟動
1. 將 app.py、cars.csv、requirements.txt 放在同一資料夾
2. Terminal 執行：
   pip install -r requirements.txt
   streamlit run app.py

## 功能
- 隨機抽車
- Wikimedia Commons 自動找車圖
- 看圖猜價格 / 直接揭曉 / 產險情境題
- 品牌與價格級別篩選
- cars.csv 可自行新增車款

## 注意
第一版除 Toyota 已按查得之 2026 台灣官方售價整理外，其餘價格為教育用約略級距。
正式對外授課前，請以各品牌台灣官網或保發中心汽車重置價格最新資料校正。
